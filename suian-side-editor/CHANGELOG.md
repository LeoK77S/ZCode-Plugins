# 更新记录

本文件记录 suian-side-editor 的用户可感知变化，版本独立于其他业务插件。

## 未发布

## [0.2.0] - 2026-10-14

新增选区评论与主对话聚合胶囊，沿用原有文本编辑、保存和恢复。发送处理中采用用户已接受边界风险的尽力禁用方案，完整原生并发仍未完成。

### 新功能

**选区评论与主对话聚合**（Desktop 本机工作区）（#46、#47）

- 从当前选区创建独立评论快照，保留完整位置、选文、评论、可信归属和未保存标记；添加评论不保存源文件。
- 多条评论合并为主对话胶囊，模型回复留在主对话，继续编辑不改写已有快照。
- 主对话处理中尽力禁用新增和已开表单提交，tooltip 说明原因，保留未提交正文；未知或断连只阻止评论，文件编辑和保存继续可用。
- 用公开 V4 临时快照及同水位当前分支历史页识别完整批次。已完整观察的受理证明在后续历史失败时继续保留，不按空队列或模型结束猜测成功。

### 其他改进

- common 0.1.2 增加向后兼容的 Channel 监听入口与固定官方 V4 逻辑帧 decoder；保留 Apache-2.0／NOTICE、Zod MIT 许可及逐源 SHA 清单。
- 取消评论观察时，在既有 RPC 时限内等待自有订阅 ACK 和退订；超时／断连明确报告无法确认释放，不把载体关闭当作远端已清理。

> **已知原验收缺口**：两次观察之间已受理又取消、且当前投影已无该队列／用户输入时，A 仍可能随新评论 B 复活。该原 #47 验收仍失败，未获得豁免，不自动归入 #57；#42／46／47／48 保持开启。

> **发送边界风险**：已同意的是尽力禁用方案。状态可能迟到，恢复可能早于原生旧胶囊清理；running 代理可能锁定整轮回复，不能称为同步 pending 或原子安全。完整并发保证仍待 #57。

> **验证范围**：最终 f6 代码的 SDK55、实际构建浏览器65和 common98 有限定通过证据，两项可修 P2 已闭合。旧严格 schema 的 Native 失败保留；公开 V4 A 普通发送／B 排队的全文 JSON 与 API 审批通过属于接口 probe。最终 f6 新缓存／可见 guest 尚未执行，正式缓存验收、完整首版及用户验收未通过；详细记录见 [评论验证](docs/comment-guard-verification.md)。

## [0.1.0] - 2026-10-13

首次提供本机已有 UTF-8 文本的独立侧栏编辑器。保存方式、外部冲突处理与会话恢复均有本地契约和限定原生验证。

### 新功能

**侧栏文本编辑**（Desktop 本机工作区）（#41、#43）

- 顶部文件夹按钮打开右侧目录树，包含隐藏文件与 node_modules；文本区域按剩余宽度居中。
- 单击使用一个斜体临时页签，双击或首次编辑固定页签；打开的文件可切换和关闭。
- 编辑已有 UTF-8 文本，通过保存按钮或 Ctrl+S 写回，保留 BOM 和文件换行特征。

**保存方式与冲突处理**（Desktop 本机会话）（#44）

- 默认手动保存，可在内部按钮切换为自动保存；选择按会话持久化并更新新会话默认，已有其他会话保持自己的选择。
- 自动模式在停止输入 800 毫秒、切换文件页签或切入自动模式时尝试保存。
- 无未保存编辑时同步外部修改；发生冲突时保留正文并暂停自动写回，由用户选择重新读取或保留编辑。
- 文件变化通过已受审登记的只读资源订阅同步，稳定文件不再反复调用读取工具。

**会话编辑恢复**（Desktop 本机会话）（#45）

- 恢复打开文件、页签顺序、临时／固定属性、当前页、各页阅读位置和未保存正文。
- 恢复副本独立存入插件外置 SQLite，页面显示同步回执；副本成功不等于源文件已保存。
- 恢复遇磁盘冲突或读取失败时保留未保存正文，干净文件读取最新磁盘内容。

### 其他改进

- 提供原生 setup 技能，安装锁定依赖并通过 common 的实际入口建立公共包链接；构建 HTML 和第三方许可随包提供。

> **当前范围**：尚未提供选区评论与主对话评论胶囊。宿主缺少关联发送批次的消费通知，评论 #46／47 及完整首版 #48 仍受 H3 门槛阻塞；PPT、远程工作区与新建、重命名、删除文件不在本版范围内。

> **验证边界**：核心实现原 SDK 基线为 37 项；加入市场登记契约后，本轮完整 SDK 回归 39 项通过。浏览器 55 项／组及三种限定原生生命周期验证沿用核心实现的通过记录。临时隔离入口的结果不等于正式缓存安装与用户产品验收；详细范围见 [实施总记录](docs/development-verification.md)。
