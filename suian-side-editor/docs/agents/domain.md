# 侧栏编辑器领域文档入口

沿用本仓库既有布局，不另建一份术语表。

- 术语：[根 CONTEXT.md](../../../CONTEXT.md)，侧栏编辑器术语明确标为规划中。
- 设计：[设计澄清](../design-discussion.md)，只将用户已确认的选择记为决定。
- 规格：[首版规格](../text-editor-spec.md)，需求共识与工程选型已整体批准。
- 实施：[票索引](../text-editor-tickets.md) 与已发布票的本地记录，能力条件未满足时保持阻塞。
- 架构：[ADR 目录](../adr/)，记录背景、状态、决定与影响。
- 开票：[GitHub 开票约定](issue-tracker.md)。按明确发布指令创建 Issues，不把本地标识当作实际票号。

首版不包含辅助会话、插件内模型回复或 PPT 编辑。
