# 会话保存模式与编辑恢复副本由插件持久化

**状态**：2026-10-12 已接受产品语义、自动保存触发、内部页签关闭行为与状态所有权。存储技术和恢复副本回执已随规格批准，尚未实施。

## 背景

用户要求保存模式可在内部 UI 切换，设置持久化；当前会话修改设置时更新全局默认，但不改变其他已有会话的选择。关闭重开还需要恢复文件页签、未保存正文、当前页面和阅读滚动位置。

宿主 `widgetState` 只在 Renderer 内存中保留，应用重启后为空。原生面板关闭不能由页面阻止，`ui/resource-teardown` 默认只有 500 ms，不能作为唯一持久化时点。

来源：[UI 生命周期契约](https://github.com/zai-org/ZCode/blob/aac4755666d09fdcd70272fcf063c077a639015f/packages/ui/src/plugin-ui/CONTRACT.md#L5-L15)、[状态存储](https://github.com/zai-org/ZCode/blob/aac4755666d09fdcd70272fcf063c077a639015f/packages/ui/src/plugin-ui/app/pluginUiWidgetStateStore.ts#L1-L17)、[关闭收尾](https://github.com/zai-org/ZCode/blob/aac4755666d09fdcd70272fcf063c077a639015f/packages/ui/src/plugin-ui/app/pluginUiHostTeardown.ts#L23-L54)。

## 决定

- 保存方式支持自动与手动，首次全局默认值为手动。
- 会话首次使用编辑器时继承全局默认；已有会话继续使用自己的已持久化选择。
- A 会话切换模式时更新 A 的模式和全局默认；已有 B 会话保持原选择。重开 A 时恢复 A 的模式。
- 自动保存在停止输入 800 ms 后触发；切换内部文件页签立即尝试保存；切换为自动模式时保存已有未保存内容。手动模式通过保存按钮或 Ctrl+S 写回。
- 由插件持久化恢复副本，恢复打开文件、未保存正文、当前页面与各文件滚动位置；不依赖宿主永久保活或应用重启后保留 widgetState。
- 恢复副本与写回原文件分开，不能将恢复副本保存成功显示为原文件已经保存。
- 外部修改发生时，未编辑的内容自动刷新；存在未保存编辑时保留当前正文、提示冲突并暂停自动写回。
- 关闭有未保存编辑的内部文件页签时，提供保存并关闭、放弃修改、取消；整个原生面板的关闭由宿主处理，依靠编辑过程中的恢复副本恢复。

## 影响与待定项

持久化发生在编辑和状态变化过程中，不把唯一保存操作放在关闭回调。首版集成验证必须覆盖侧栏销毁、离屏回收与应用重启恢复，以及多会话保存模式相互隔离。

规格采用插件自有 SQLite 与独立持久化回执，见 [ADR 0004](0004-editor-owned-sqlite-state.md)。外部冲突按已接受的重新读取或保留编辑处理，不把保留正文当作覆盖磁盘的授权；不新增跨窗口同步框架。
