## 问题与交付

自动保存需要正确的触发、会话默认规则与磁盘冲突处理，不能让一个会话的设置修改其他已有会话。

沿用插件自有 SQLite 持久化全局默认和会话模式；实现 800 ms、内部切页及切自动模式触发，所有写回走已有版本检查保存入口。

## 责任范围

suian-side-editor 的状态库、模式工具、自动保存调度、外部文件更新处理与页面状态。

正文及全部阅读状态的重启恢复在 SE-05 实现；模式本身在本票已完整持久化。

## 验收条件

- [ ] 首次默认手动；A 切换模式在一个事务中保存 A 与全局默认。
- [ ] 已有 B 保持自己的模式；新 C 继承最新默认；重新打开 A 恢复 A。
- [ ] 停止输入 800 ms 后尝试保存；内部切页立即尝试；切到自动模式保存已有脏正文。
- [ ] 切手动模式取消尚未开始的自动任务；已经完成的旧保存回执不覆盖新的编辑状态。
- [ ] 外部修改：干净正文自动刷新；脏正文保留、提示冲突并暂停该文件自动写回。
- [ ] 用户选择重新读取时明确放弃当前编辑；选择保留编辑不被理解为静默覆盖授权。
- [ ] 权限失败、文件删除或持久化失败明确显示；不会误报源文件或设置已保存。
- [ ] 使用可控计时与实际临时文件验证触发和冲突，不靠长时间 sleep 制造通过。
