## 问题与交付

开发工作树中的局部验证不能证明原生缓存安装、公共依赖链接及当前完整流程可用。交付可独立安装且依赖 common 的原生插件，核对实际加载产物，完成当前范围的端到端验收并记录脱敏证据。

文件浏览、编辑、保存、冲突、恢复和可信归属要求保留。评论必须包含创建时完整字段，正常受理清理、失败保留、排队受理及受理后缓存不复活；按已核公开会话状态尽力禁用全部提交入口、tooltip 说明原因、选区与未提交正文保留，按实际状态恢复。状态可能迟到，恢复可能早于 Renderer 清理的残余风险已由用户接受。若模型 running 用作保守代理，可能整个回复期间禁用；它不等于请求在途。

原完整要求由 SE-11 独立承接：发送在途可继续添加 B，受理 A 只清理 A，失败 A/B 保留，独立身份／批次、重连和晚到回执安全，最终移除临时禁用。它不再是本票当前必过条件，也不因本票通过而完成。

- [ ] 运行数据落本插件外置 dataPath；用户正文、会话 ID、个人路径与凭据不进入 Git 或验收汇总。
