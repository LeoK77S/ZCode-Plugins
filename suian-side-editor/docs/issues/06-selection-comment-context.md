## 问题与交付

编辑正文可能未保存或继续变化，模型需要创建时的准确选文与文件位置。选择实际 CodeMirror 文本并填写评论后，将固定快照加入当前主输入区上方的聚合胶囊；模型回复始终留在主对话。

当前评论快照包括稳定独立 commentId、可信 workspaceIdentity／sessionId、完整 sourcePath／sourceTitle、1-based startLine／endLine、selectedText、comment 和 containsUnsavedEdits。摘要简短不意味着提交字段可以省略。

当前按已核公开会话状态尽力禁用所有添加／提交评论入口，包括已打开表单提交；保留选区与未提交正文，tooltip 明确原因和真实恢复条件。状态可能迟到、解除禁用可能早于 Renderer 清理的残余风险已获用户接受。若用模型 running 作保守代理，可能整个回复期间锁定，不能称为请求在途。完整在途追加移至 SE-11，未来具备能力后移除临时禁用。

## 责任范围

suian-side-editor 的选区评论表单、快照数据和主对话适配；采用 SE-02 已核实的公开接入、实际状态和已知限制，不猜宿主接口。

发送受理后的缓存清理、正常／失败／排队及临时禁用闭环由 SE-07 完成。本票必须与该保护边界兼容；单独快照可用不代表当前评论闭环完成。

## 验收条件

- [ ] 从实际 CodeMirror 选区创建快照，保存稳定独立 ID、可信工作区／会话、完整路径／标题、1-based 起止行号、实际选文与评论。
- [ ] 未保存正文允许评论，明确标记包含未保存编辑；添加评论不隐式保存源文件。
- [ ] 继续编辑、保存或外部修改不改写已创建评论的选文、行号和未保存标记。
- [ ] 多条评论聚合提供，每条完整信息进入实际提交正文；胶囊摘要不导致字段丢失。
- [ ] 完整明细的可查看形式按 SE-02 实际宿主能力验收，不假定 structuredContent 自动渲染原生布局。
- [ ] 评论只进入当前可信绑定主对话，工作区／会话隔离，不插入可见输入文本、不新建辅助会话、不在插件接收模型回复。
- [ ] 已核公开状态驱动全部提交入口尽力禁用，包括已打开表单；保留选区与未提交正文，tooltip 可查看并说明原因、实际观测状态与恢复条件。
- [ ] 状态未知／断连如实显示，不当空闲；按实际接口恢复。若用 running 作保守代理，明确可能整个回复期间禁用，不把它等同在途；不承诺同步／原子无竞态。
- [ ] 测试通过真实编辑器选区与外部主对话适配边界，不只测试序列化函数；实际公开接口、禁用、内容保留和恢复行为须经验证，不能把风险授权当作实现完成。
- [ ] 原完整并发能力由 SE-11 单独承接，不作为本票当前完成条件，也不因本票通过被宣称完成。

实际构建页面创建评论快照；MCP／适配边界验证可信归属、完整提交正文及所有提交入口的禁用／恢复；Desktop 验证胶囊、tooltip 与未提交内容保留。

可执行行为先见契约红灯再实现。首次长命令落盘日志及退出码，后续统计只读已有日志；入库仅保留脱敏证据。当前文档调整未完成临时功能实现，技术自检不等于用户验收。
