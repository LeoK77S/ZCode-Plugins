## 问题与交付

首版只操作本机工作区，远程工作区的读写、身份、冲突和恢复必须沿实际远端能力重新确认。

首版之后单独澄清远程工作区范围并核实原 Host 文件能力，再形成可实现规格和子票。本占位不假定远端文件已暴露可写接口。

## 责任范围

未来 suian-side-editor 远程文件路径与状态；真实可复用连接能力归 common。

只登记用户要求的后续特性，不扩展首版完成条件。

## 验收条件

- [ ] 进入实施前单独确认支持的远程工作区类型和文件范围。
- [ ] 核实文件读取、保存版本检查、会话／远端身份与恢复数据归属的真实接口。
- [ ] 验证断连与冲突下不把本地路径当成远端路径、不静默覆盖。
- [ ] 制定贯穿远端读写、编辑页面与真实宿主的验收步骤后再标为可实施。

## 验证与完成证据

待后续范围及接口核实后确定；本轮不执行远端读写。

可执行行为遵循契约测试先行。首次长命令落盘记录日志和退出码；只汇总脱敏证据。通过依赖票还必须满足该票声明的实际能力条件；调查结束本身不会解除能力阻塞。
