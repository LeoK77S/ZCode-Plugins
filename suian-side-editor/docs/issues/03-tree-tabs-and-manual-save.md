# SE-03 · 浏览目录、打开临时或固定文件页并手动编辑保存

**状态**：已发布，尚未实施；依赖与实际能力条件未满足前保持阻塞。

**GitHub**：[#43](https://github.com/ONEGAYI/ZCode-Plugins/issues/43)。

**Blocked by**：[#41 · SE-01](https://github.com/ONEGAYI/ZCode-Plugins/issues/41)。

规格：[首版规格](../text-editor-spec.md)。顺序：[票索引](../text-editor-tickets.md)。本地标识不是 GitHub Issue 编号。

## 问题与交付

首版需要可用的本地文本编辑闭环，既保留连续预览，也保护已经编辑的文件页。

实现按需目录树、剩余宽度居中的编辑器、多文件临时／固定页签及手动保存。保存基于实际磁盘版本，关闭脏页提供三种明确选择。

布局与视觉遵循实施期间用户提供的原生文件侧栏截图，参见 [视觉参考](../design-discussion.md#实施期间的视觉参考)。内部页签、面包屑、行号正文与右侧目录树需在真实构建页面中核对。

## 责任范围

suian-side-editor 的目录／文本／保存工具、CodeMirror 页面、内部页签与契约测试；不增加公共编辑器框架。

不加入自动保存、重启恢复或主对话评论；这三项由独立后续票完成。

## 验收条件

- [ ] 顶部文件夹按钮开关右侧目录树；只展开所需层级，node_modules 和隐藏文本文件可浏览。
- [ ] 目录树展开／收起时，主区域按剩余宽度居中；整体编辑器占插件侧栏主体。
- [ ] 单击复用唯一未编辑临时页并显示斜体；双击与首次编辑立即固定为正体。
- [ ] 单击已有页只激活，不产生重复页；保存后的固定页仍保持固定。
- [ ] 保存按钮与 Ctrl+S 只保存对应编辑正文；成功后返回新基线，期间新输入不能被错误标为已保存。
- [ ] 磁盘内容与基线不符时拒绝保存，编辑正文保留；保存失败显示错误，不清除 dirty 状态。
- [ ] 保留 UTF-8 BOM、CRLF／LF 与中文正文；未修改保存不改变字节。
- [ ] 脏页关闭的保存并关闭／放弃修改／取消分别生效；保存失败或冲突不关页。
- [ ] 临时工作区的契约测试先红后绿，浏览器测试运行真实构建页面。

## 验证与完成证据

MCP Client + 实际临时文件验证保存与版本冲突；页面测试验证页签转换、关闭结果与宽度布局；原生侧栏烟测。

可执行行为遵循契约测试先行。首次长命令落盘记录日志和退出码；只汇总脱敏证据。通过依赖票还必须满足该票声明的实际能力条件；调查结束本身不会解除能力阻塞。
