## 已验证的评论行为

- 选区评论保留可信会话／工作区、完整路径、独立评论与批次 ID、标题、1-based 行号、选文、评论和未保存标记；加入主对话不保存源文件，后续编辑不改写已有快照。
- 全部添加／提交入口使用公开会话状态尽力禁用，包括已经打开的表单。tooltip 说明实际观测状态；未知／断连不当空闲，保留评论正文与选区，文本编辑和保存继续可用。
- 聚合胶囊提供完整快照。正常受理及排队受理只消费完整匹配的本插件批次；发送失败、残缺数据、缺少受理证据均保留评论，不以模型结束猜测成功。
- 评论状态资源首次经可信 app-only 工具登记，随后通过公开资源订阅读取。服务端只返回状态、原因与本插件批次识别结果，普通聊天正文不返回页面；资源退订及服务关闭释放登记。

上述结果来自真实 MCP、临时数据库和实际构建页面，Host 状态与异步门闩由外部测试边界注入。它们证明对应契约，不能代替 Native 真实发送、原生胶囊清理和评论缓存闭环实测。
