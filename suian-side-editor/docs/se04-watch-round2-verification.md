## 首次反馈与历史保护

`red.log` 普通／脏目标均命中 `2 !== 1`。同一次运行的保存项遇到 Playwright 时钟暂停目标落在过去，属于驱动错误；将夹具暂停时刻稍向前移后，`save-red.log` 命中“状态仅已保存”的产品断言。单项反馈约 0.82 秒。

首次 `green.log` 仍失败，是测试直接取 CodeMirror 容器 `textContent`，其 DOM 行间不包含换行。改为公开行节点逐行拼接后，`green-2.log` 三项通过；没有为测试断言改变换行实现或文件正文。这两类驱动错误与实际红灯分别留证。

首次 `content-final.log` 把 Git blob 与 Windows 检出文件按原始 SHA 比较，CLI 的四个 CRLF 与 blob 的 LF 因而不同。逐项记录字节／SHA／CRLF 数后，仅规范化 CRLF 的源码比较均相同，`content-final-2.log` 通过。没有改这些文件或为换行差异重跑 SDK；旧 90／44 证据仍按原始字节核对。

首次新构建前逐文件字节／SHA 核对旧 90 项与上一轮 44 项，均不变；旧两个清单 SHA 分别为 `a2c54d2d…`、`eea197c9…`。Source 6d44 的 HTML 319186 字节／`ec926d1c…` 及许可已冻结在本轮独立目录。新日志、退出码、截图和清单全部另存，本轮截图预先指定新目录。

根冻结的 278 项 Native 历史未操作。原 Native ID7 成功、ID8–12 稳定文件读审批反复弹出、ID13 拒绝后暂停的失败不改写；新 Native 继续暂停，待固定集成和独立两轴复核后串行验收。
