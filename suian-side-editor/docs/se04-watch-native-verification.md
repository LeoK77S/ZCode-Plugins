## 实际行为与磁盘核对

- **稳定读取与通知**：alpha 首读后，subscribe/read 的 URI 与工具登记一致。20 秒观察窗内没有新增 `read_editor_text`、没有新增协议请求，公开 pending 前后均为 0。外写 35→54 字节，在 `05:40:36.913Z` 收到同 URI 通知，下一毫秒发起 ID8 资源读取并刷新；有限窗口不证明所有未来空闲期。
- **三种自动触发**：Manual 中编辑后，ID9 切 Auto 的成功回执触发 ID10 保存，磁盘为 43 字节。随后 idle 的 ID12 成功写为 36 字节。BOM／CRLF 文件输入完成后 8 ms 普通切页，ID23 在 800 ms 前发起保存；磁盘 46 字节，BOM 和 CRLF 保留。原生只记实际时点；精确 799／800 ms 和旧回执交错仍来自实际构建契约。
- **切手动取消**：新输入完成后 2 ms 点击模式按钮，ID14 回执为 Manual。后续两秒没有新协议请求，页面保持新脏正文，磁盘仍为先前 36 字节，未启动自动保存。
- **脏冲突与放弃确认**：磁盘外写为 59 字节后，ID15 资源快照使页面提示冲突、保留编辑。保留按钮和取消重新读取均不发工具；切 Auto 成功后仍不自动保存。ID17 显式保存拒绝旧基线，磁盘不变。只有确认“放弃编辑并重新读取”的 ID18 成功后，页面才换成外部正文并变干净。
- **有效阅读位置**：长文件 180 行，真实 mouseWheel 使 scrollTop=1250，scrollHeight=3916、clientHeight=579。外改后 ID28 资源读取更新正文，scrollTop 仍为 1250；没有直接写 DOM 滚动值制造结果。
- **退订**：打开另一临时文件替换长文件，ID30 unsubscribe 与原 ID26 subscribe URI 相同并有 ACK。内部关闭删除文件，ID34 同样取得 ACK。退订后再次外写长文件，两秒内无新协议请求，旧页不在页签中。这是内部文件页关闭／替换证据，不是 Host 页面销毁或 H4 回收证据。
- **删除**：只删除自有测试文件，ID33 快照返回 `file_not_found`，UI 明确“文件不存在或已删除”，原正文保留。原 29 字节文件已恢复；关闭该文件页后完成退订。

## 两类故障及恢复

**源文件权限故障**仅作用于自建 `permission.txt`。临时 ACL 禁止写入，ID38 保存经单次授权后返回 `permission_denied`；页面保留编辑，磁盘仍为原 31 字节。

恢复时首次脚本的 SDDL 逐字相等断言失败，原日志退出 1 保留。窄核对证实 owner、group 和 DACL 二进制均与原值相同、Deny 数为 0；差异仅是 Set-Acl 增加 `DiscretionaryAclAutoInherited` 控制标志。普通 `r+` 打开成功且未写字节。随后 ID39 Ctrl+S 成功写回保留的编辑，磁盘 38 字节；没有修改目录或真实用户文件权限。

**模式持久化故障**仅在新 wrapper 的自有数据库制造只读共享锁。代理以 readOnly 连接执行 `BEGIN` 和 `SELECT`，没有 SQL 写入。ID41 的模式更新不能完成事务，返回 `state_storage_error`；页面仍 Auto，并明确提示“保存方式未确认持久化”。释放读事务后，新只读连接确认 A 与 global 仍 Auto，说明失败没有提交新模式。ID42 更新成功后，两者均为 Manual，设置错误清除。

源文件在 ID39 已保存，与 ID41 模式事务失败是两个独立事实。数据库没有搬动或重建，未读 Core DB。只读锁释放后辅助进程的 stdin 监听保持存活；仅对该自有辅助 exec 做 Ctrl+C 收尾、退出 1，GUI／Host／根控制器均保留。

## 复用范围、冻结及下一步

旧 DC 产物的 A／B／C 首次 Manual、已有 B 不变、新 C 继承 Auto、A 重开恢复模式，归旧 wrapper 和旧数据根。其 278 项证据及重复读取失败保持原字节。本轮没有重复该多会话链；根只读比较确认 `dc718839…1e30d847` 的 `editor-settings.mjs` blob 相同，因而复用未变模式语义的既有证据。新 wrapper 另有首次 Manual、A/global 写回、失败回滚和恢复的实际结果，不能拼成同一数据根重开验收。

精确时钟、受控在途旧回执、订阅失败／重绑定时序等已有 SDK／实际构建契约，本轮没有在 Native 私有暂停或状态注入重演。没有因此重跑已绿的 33 SDK／42 浏览器、common95 或 app109。

本轮未覆盖新 wrapper 的 A／B／C 多会话重开链、Native 可控受理暂停／旧回执交错、强制订阅失败及改指重绑定交错、本轮视觉、Host 真正 dispose／应用重启。前三项分别保留历史或构建契约的来源；后两类生命周期属于 H4／SE-05 后续条件，不能由内部文件退订放行。
