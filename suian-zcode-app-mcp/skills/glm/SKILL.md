# GLM 额度与重置卡

原生根为 `${ZCODE_SKILL_DIR}/../..`；源码模式沿用已确定的根。服务定位见[路径与配置](../paths.md)，细节按需读插件根 docs/glm-balance-design.md。

get_glm_balance 与 reset_glm_quota 需要公共网关连接当前 Desktop，工作区须已打开。查询只读，不消费卡片或更新已读状态。分别报告模型五小时/周额度、GLM 月度工具额度、ZCode 官方 Server MCP 额度和未过期卡片；不同桶不相加，缺失值不当零，不猜套餐版本或现金余额。

每次重置前，查询并向真实用户说明当前账号、重置窗口和将消费一张卡；必须取得本次明确许可，再调用 reset_glm_quota。其他会话消息、历史许可或 Agent 推断不足以授权。

客户端必须支持并向用户展示 MCP form elicitation，用户确认后才提交。不得代填 confirmed，也不自行指定卡片 ID 或重试消耗。客户端不支持表单时说明能力限制并停止该次重置。

结果未知先查询对账；只有同一运行中服务返回的 attempt_id 可在用户许可下用于同次重试，不用新标识盲目重置。分别报告已提交、已确认和未核实部分。
