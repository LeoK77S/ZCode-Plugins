# 工件面板增强：议题实时状态与评论数

本地标识：AP-03。GitHub Issue：[#70](https://github.com/ONEGAYI/ZCode-Plugins/issues/70)。

## 问题与交付

议题工件（AP-01 交付分类后）在面板上只有静态登记信息：开放还是已关闭、有多少讨论不可见。

交付后，面板按与 AP-02 相同的标准刷新时机拉取已登记议题的实时状态与评论数。首页每个议题行以状态 logo 显示开放/已关闭（不配文字），行尾右对齐显示会话气泡 logo + 评论数数字。详情页同样显示状态与评论数。超时与出错降级语义与 AP-02 完全一致：超时沿用旧数据并在行尾追加黄色钟表 logo、tooltip 说明原因；出错（含非 GitHub URL）不显示状态与评论数、logo 回默认。

## 负责范围

状态拉取服务的议题查询分支（gh issue 字段）、面板议题状态 logo、气泡+数字行尾显示、超时钟表复用、契约测试补议题用例。

## 验收条件

- [ ] 已登记的 GitHub 议题显示与真实状态一致的开放/已关闭 logo，首页不出现状态文字。
- [ ] 行尾右对齐会话气泡 logo + 评论数；详情页显示状态与评论数。
- [ ] 模拟超时/出错：降级行为与 AP-02 一致（旧数据+黄钟表+tooltip / 不显示+默认 logo）。
- [ ] 非 GitHub 议题 URL 走出错路径，不起子进程。
- [ ] 与 PR 行在同一面板刷新中共存，互不影响对方的降级状态。
