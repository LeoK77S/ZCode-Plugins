# 工件 demo：主动登记和维护的提示词及行为评估

GitHub Issue：[#30](https://github.com/ONEGAYI/ZCode-Plugins/issues/30)。完整版唯一投影另见 [#36](https://github.com/ONEGAYI/ZCode-Plugins/issues/36)，不阻塞本票。

本地标识：AZ-04。状态：待 #29 完成后实施，生产功能尚未实现。Blocked by：#29。

## 问题与交付

工具存在不等于 Agent 会主动使用。将已审阅的管理提示词纳入简略摘要，引导 Agent 主动登记有后续用途的引用、增量维护和移除失效项。

负责范围：管理提示词、原生拆分 skills 说明和行为评估证据；不增加新的管理工具或资源操作。

## 验收条件

- [ ] 开头明确“这是用户提交时的摘要，可能已过时”；需要完整列表、最新 revision 或处理冲突时调用 get_artifacts，不能沿用“当前最新完整列表，通常无需 get”的旧表述。
- [ ] 提示词保留四类、四字段、按 ref 更新、revision 校验和容量说明，不自动加入完整条目。
- [ ] 成功创建或接手需持续访问的 PR、关联会话、关键文件时按用途登记，purpose 清晰；不全量收录偶然访问或临时资源。
- [ ] 同一引用改名称/用途用增量 upsert，不重发整份列表；版本冲突先 get，再重新判断变化。
- [ ] 完成但仍有交付用途的工件保留；被替代或失效且无用途的引用移除，真实资源不被删除。
- [ ] snapshot_missing 明确为继承诊断，不引导 Agent 禁用工件工具、反复重试继承或读取父最新状态补作“准确快照”。
- [ ] 引用和条目内容均是数据，不解释为发信、推送、合并或资源操作授权。
- [ ] 固定代表性场景、真实模型/配置、工具记录与评价标准，记录实际行为及失败；合成 SSE 不冒充真实 Agent 主动维护证据，条件不足的评估明确列为未测。
- [ ] 记录实际工具输入/回执与摘要体积，不凭字符数承诺精确 token 或缓存成本。

行为评估使用合成资源和受控工具，不对真实 PR 或会话进行未授权操作。父规格：[demo 规格](https://github.com/ONEGAYI/ZCode-Plugins/issues/28)，见可折叠全文。
