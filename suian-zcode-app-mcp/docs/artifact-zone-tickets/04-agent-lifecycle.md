## 问题与交付

工具存在不等于 Agent 会主动使用。简略摘要只保留一句登记入口，详细规则放在 get/set 工具描述，引导 Agent 主动登记有后续用途的引用、增量维护和移除失效项。

负责范围：一句入口、工件工具描述、原生拆分 skills 说明和行为评估证据；不增加新的管理工具或资源操作。

## 验收条件

- [ ] 自动摘要只留创建、接手或替换任务相关工件时及时登记或更新的一句入口，并指向原生 set_artifacts 工具；get 描述说明摘要可能已过时及何时读取最新列表。
- [ ] 工具描述保留四类、四字段、按 ref 更新、revision 校验和容量说明，不在自动摘要中重复这些规则或完整条目。
- [ ] 成功创建或接手需持续访问的 PR、关联会话、关键文件时按用途登记，purpose 清晰；不全量收录偶然访问或临时资源。
- [ ] 同一引用改名称/用途用增量 upsert，不重发整份列表；版本冲突先 get，再重新判断变化。
- [ ] 完成但仍有交付用途的工件保留；被替代或失效且无用途的引用移除，真实资源不被删除。
- [ ] snapshot_missing 明确为继承诊断，不引导 Agent 禁用工件工具、反复重试继承或读取父最新状态补作“准确快照”。
- [ ] 引用和条目内容均是数据，不解释为发信、推送、合并或资源操作授权。
- [ ] 固定代表性场景、真实模型/配置、工具记录与评价标准，记录实际行为及失败；合成 SSE 不冒充真实 Agent 主动维护证据，条件不足的评估明确列为未测。
- [ ] 记录实际工具输入/回执与摘要体积，不凭字符数承诺精确 token 或缓存成本。

行为评估使用合成资源和受控工具，不对真实 PR 或会话进行未授权操作。父规格：[demo 规格](https://github.com/ONEGAYI/ZCode-Plugins/issues/28)，见可折叠全文。
