# local-only 按发行包身份自动选择随包适配档案

**状态**：2026-10-22 用户确认实现自动路由并补齐规格。

## 背景

[ADR 0003](0003-local-only-desktop-patch.md) 限定单个 Windows 3.16.2 包。现有工具只拥有一套身份和注入规则；未来替换全局常量会丢失旧包管理能力。已打补丁包的当前摘要又与原版不同，无法只凭当前摘要选择原版规则。

## 决定

- 每个已验证发行包使用稳定适配档案 ID，独立维护补丁修订号、入口和注入实现。注册表、新旧档案均随公共插件发布。
- 原包按平台、exe FileVersion 和完整原版 asar 摘要唯一匹配；已 patch 包通过有效状态中的原版摘要路由，并核对当前字节及显式档案信息。
- 兼容历史格式 1 候选/状态的精确身份映射；读操作不迁移文件。新候选和状态格式 2 显式记录档案 ID 与平台。
- apply 先核对候选和实际目标属于同一档案，再进入还原或写入。修订号仅在同一档案内比较，拒绝降级和跨包覆盖。
- 删除生产 CLI 的任意包身份覆盖参数。新增真实支持必须提交对应档案和隔离验收证据，不靠改 JSON 宣称兼容。
- 当前档案保持 v3 注入及输出字节，setup、网关和业务插件沿用现有链路。

## 影响与取舍

新工具能继续管理注册表保留的旧包；维护者需要持续携带旧档案并运行兼容回归。不能承诺未知版本自动适配。未知或损坏记录明确失败，避免把错误归因于“未 patch”而覆盖目标。

静态注册避免安装时网络依赖与动态代码分发。后续若真实支持的操作系统布局发生变化，另行扩展识别边界。本次仅建立路由机制，不增加真实支持包数量。

行为、维护步骤和验收见[自动路由规格](../local-only-routing-spec.md)。
