# local-only 自动路由开发验证

**结论**：自动路由、历史记录兼容及发布分发验证通过。当前真实支持仍为 Windows 3.16.2.8769 的既定包；没有新增真实版本支持，也未操作用户日常安装。方案见[规格](../local-only-routing-spec.md)和 [ADR 0004](../adr/0004-local-only-patch-routing.md)。

## 交付行为

- status、prepare、apply、restore 共用平台、exe FileVersion、原版 asar SHA-256 的精确路由；新档案保留旧档案，修订号分别维护。
- 历史格式 1 候选与状态无需预先改写；新候选和状态格式 2 记录 profileId/platform。
- 跨档案候选、降级、错误身份或平台、未知格式、损坏状态在写目标前失败。生产 CLI 移除任意身份 JSON 覆盖入口。
- 构建分发注册表和完整档案目录；独立发布目录可实际导入全部档案与 CLI。
